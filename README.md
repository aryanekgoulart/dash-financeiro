# 💰 Dashboard Financeiro Pessoal

Projeto em **Power BI** desenvolvido com o objetivo de organizar gastos pessoais e obter maior controle sobre as finanças mensais por meio da **Análise de Dados**.
O projeto surgiu de uma necessidade pessoal e evoluiu para um dashboard completo, aplicando conceitos de **modelagem de dados**, **DAX** e **design visual**, sendo hoje parte do meu **portfólio em Análise de Dados**.

# 📌 Sobre o Projeto

Este foi um pequeno projeto pessoal criado para melhorar a organização financeira do dia a dia.  
Ao longo do desenvolvimento, estruturei as informações financeiras, apliquei técnicas de modelagem de dados e desenvolvi medidas personalizadas em DAX para análises mais profundas.

Além da parte analítica, utilizei o **Figma** para criar o fundo visual do dashboard, garantindo uma apresentação mais intuitiva, limpa e personalizada.  
Com o resultado final, decidi compartilhar o projeto como forma de aprendizado e demonstração prática de habilidades.

# 📊 Visões do Dashboard

O dashboard oferece uma visão completa da vida financeira, dividida em três principais áreas:

### ✅ Visão Geral
- Receita total
- Despesas totais
- Saldo mensal
- Investimentos
- Metas mensais por categoria

### 💳 Análise de Cartões
- Total de gastos por cartão
- Evolução dos gastos ao longo dos meses
- Comparativo entre cartões

### 📥 Controle de Recebíveis
- Valores a receber de terceiros
- Evolução mensal dos recebimentos
- Status das parcelas (em aberto / recebidas)

## 🛠️ Habilidades Aplicadas

- Modelagem de dados com múltiplas tabelas relacionadas  
- Criação de medidas DAX para cálculos personalizados  
- Análise financeira pessoal  
- Design de dashboards interativos e segmentados  
- Criação de layout personalizado no Figma  
- Boas práticas de visualização de dados  

## 🧠 Tecnologias e Ferramentas

- Power BI  
- DAX  
- Figma  
- Excel / CSV (base de dados)  

## ⚠️ Observação Importante

**Todos os dados utilizados neste projeto são fictícios** e foram criados exclusivamente para fins de estudo, demonstração e apresentação. Nenhuma informação financeira real foi exposta.
